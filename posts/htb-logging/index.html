SVC_RECOVERY 拥有 Outbound Object Control（出站对象控制）指向 MSA_HEALTH$，这意味着 SVC_RECOVERY 可以修改 MSA_HEALTH$ 的属性

在 Active Directory 中，拥有对 MSA_HEALTH$ 这类机器账号或托管账号的 GenericWrite 权限，最常见的利用方式是 Shadow Credentials（影子凭据）​ 攻击，即向该对象的 msDS-KeyCredentialLink 属性写入自定义的密钥，从而获取该账号的认证票据（TGT），实现提权或伪装该服务账号

原理说明：

  • 在 Active Directory 中，用户和计算机对象都有一个名为 msDS-KeyCredentialLink 的属性，它可以存储原始的公钥信息。如果攻击者对目标对象具有能够修改 msDS-KeyCredentialLink 的权限，例如适当的 GenericWrite / GenericAll 权限，则可以尝试利用 Shadow Credentials

  • Kerberos 认证的第一步是“预认证”（Pre-authentication）。除了使用密码（对称加密），还可以通过证书进行非对称方式的预认证，这就是 PKINIT 协议。在 PKINIT 认证过程中，客户端利用私钥对认证数据进行签名/证明密钥持有，KDC 根据目标账户 msDS-KeyCredentialLink 中保存的公钥验证该证明。如果验证成功，KDC 可以向该账户颁发 TGT

攻击者生成：
    私钥
    ↓
    公钥

公钥 → 写入目标账户 msDS-KeyCredentialLink

私钥 → 攻击者持有

        ↓ PKINIT

客户端使用私钥证明自己拥有对应密钥
        ↓
KDC 根据 AD 中保存的公钥验证
        ↓
认证为目标账户
        ↓
获得 TGT

流程：

  • 植入公钥：在目标账户的 msDS-KeyCredentialLink 中添加一个由攻击者自己生成的公钥。
  • 获取证书：使用这个公钥和对应的私钥，生成一个 X.509 证书。
  • 请求 TGT：利用生成的证书，通过 PKINIT 协议向域控发起 Kerberos 认证请求。因为域控在目标账户的属性里找到了匹配的公钥，认证通过，攻击者成功获得该账户的 TGT（Ticket Granting Ticket）。
  • 权限维持：在获得目标账户的 TGT 后，可以进一步利用 Kerberos 的相关认证流程获取该账户的 NT hash；Certipy 的 shadow auto 可以自动完成这一过程。即使目标用户后续更改了密码，植入的 Shadow Credentials 依然有效，除非管理员删除对应的 Key Credential，或者采取其他措施使该凭据失效。

<#
.SYNOPSIS
    Monitors the status of the "UpdateChecker Agent" scheduled task.
    Uses COM interface to avoid CIM/WMI permission issues.
#>

$TaskName = "UpdateChecker Agent"
$LogPath = "C:\Share\Logs\TaskMonitor.log"
$Timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss"

try {
    $service = New-Object -ComObject "Schedule.Service"
    $service.Connect()
    $task = $service.GetFolder("\").GetTask($TaskName)

    $State = switch ($task.State) {
        1 { "Disabled" }
        2 { "Queued" }
        3 { "Ready" }
        4 { "Running" }
        5 { "Disabled" }
        6 { "Unknown" }
        default { "Unknown" }
    }

    if ($State -ne "Ready" -and $State -ne "Running") {
        $Message = "[$Timestamp] WARN  - Task [$TaskName] is in an unexpected state: $State"
    }
    else {
        $Message = "[$Timestamp] INFO  - Task [$TaskName] health check: OK (State: $State)"
    }
}
catch {
    $Message = "[$Timestamp] ERROR - Failed to query task [$TaskName]. Exception: $($_.Exception.Message)"
}

Add-Content -Path $LogPath -Value $Message
