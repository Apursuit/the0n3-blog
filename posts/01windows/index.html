windows基础

发布于: 2026-07-14 14:58

记录windows基础知识

用户管理（cmd）

:: 查看所有用户
net user

:: 创建新用户 *
net user aaa Password1 /add

:: 删除用户 *
net user aaa /delete

:: 修改用户密码 *
net user aaa NewPass123

:: 设置用户永不过期 *
net user aaa /expires:never

:: 查看用户详细信息
net user aaa

用户组管理

:: 查看所有组
net localgroup

:: 创建新组 *
net localgroup devteam /add

:: 将用户加入组 *
:: 添加到远程桌面用户组
net localgroup "Remote Desktop Users" 用户名 /add

:: 添加到远程管理用户组
net localgroup "Remote Management Users" 用户名 /add

:: 从组中移除用户 *
net localgroup devteam zhangsan /delete

:: 查看组内成员
net localgroup administrators

常见组

Administrators：管理员组

Remote Desktop Users：远程桌面用户组

Remote Management Users：远程管理用户组（winrm服务）

网络诊断

:: 查看IP配置
ipconfig                 
:: 详细配置
ipconfig /all            
:: 清空DNS缓存
ipconfig /flushdns       
:: 释放IP
ipconfig /release        
:: 重新获取IP
ipconfig /renew          

:: 测试连通性
ping www.baidu.com       
:: 路由追踪
tracert www.baidu.com    
:: DNS解析
nslookup www.baidu.com

端口与连接

:: 查看所有连接及PID
netstat -ano             
netstat -ano | findstr :3389
:: 根据PID查进程
tasklist | findstr 1234  
:: 强制结束进程
taskkill /PID 1234 /F

防火墙

:: 查看防火墙状态
netsh advfirewall show allprofiles      
:: 关闭防火墙
netsh advfirewall set allprofiles state off   
:: 开启防火墙
netsh advfirewall set allprofiles state on

服务

:: 图形化管理
services.msc             

:: 查看服务
sc query                 
:: 启动服务
sc start spooler         
:: 停止服务
sc stop spooler          
:: 设置自动启动（注意等号后有空格）
sc config spooler start= auto

系统信息与状态

:: 系统详细信息
systeminfo                
:: 主机名
hostname                  
:: 当前用户
whoami                    
:: Windows版本
ver                       
:: 进程列表
tasklist                  
:: 任务管理器
taskmgr
