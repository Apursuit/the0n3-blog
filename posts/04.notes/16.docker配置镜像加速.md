## 推荐项目

推荐一个常用项目，Linux换源及Docker安装与换源，适合初学者和需要快速配置环境的用户，主流发行版适配不错。[https://github.com/SuperManito/LinuxMirrors](https://github.com/SuperManito/LinuxMirrors)

项目官网：[https://linuxmirrors.cn/](https://linuxmirrors.cn/)


GNU/Linux 更换系统软件源

```bash
bash <(curl -sSL https://linuxmirrors.cn/main.sh)
```

Docker 安装与换源

```bash
bash <(curl -sSL https://linuxmirrors.cn/docker.sh)
```

Docker 更换镜像加速器

```bash
bash <(curl -sSL https://linuxmirrors.cn/docker.sh) --only-registry
```
