MazeSec Merge靶机设计流程

发布于: 2026-05-22 16:53

攻击链

命令注入（www-data）

opt目录泄露mono密码（www-data>mono）

sudo -u lnnn PATH劫持（mono>lnnn）

/opt/admin/ 目录放置 admin 用户suid curl（lnnn>admin）

/etc/group可写（admin>sudo组+已知密码=任意命令执行 或 disk 组提权）

流程图

关键词：命令注入、PATH劫持、SUID滥用、/etc/group可写、Linux提权链

摘要：本文为 MazeSec Merge 靶机的设计文档，展示了一条从 Web 入口到 Root 权限的完整权限提升路径。通过构建一个多层嵌套的漏洞链来实现这一目标：首先在 Nginx/PHP 环境下利用 IP 查询工具的参数过滤缺陷触发命令注入，获取 www-data 权限；随后利用 /opt 目录下的密码泄露文件横向移动到 mono 用户；借助 sudo 配置缺陷（保留 PATH 环境变量）实施 PATH 劫持，以 lnnn 用户身份执行恶意程序；进而利用 lnnn 对 admin 用户所有的 SUID curl 程序的访问权限，通过 --config 参数读取敏感文件；最终利用 /etc/group 文件的可写权限将当前用户加入 sudo 组，结合已知的 admin 密码完成提权。该靶机重点考察了 Linux 下环境变量控制、特殊权限位利用及系统配置文件权限配置不当的综合利用技巧。

Nginx配置参考：

server {
    listen 80 default_server;
    listen [::]:80 default_server;

    root /var/www/html;
    # 添加index.php
    index index.php index.html;
    server_name _;

    location / {
        try_files $uri $uri/ =404;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/var/run/php/php8.4-fpm.sock;  # 根据实际socket文件名修改
    }
}
# 测试Nginx配置
