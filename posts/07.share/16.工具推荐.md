给大家推荐一些常用的 Windows 工具，提升效率。

## DeskBox

DeskBox 是一款面向 Windows 10/11 的桌面整理工具，解决桌面文件、文件夹与快捷方式长期堆积、难以管理的问题。通过原生文件格子与真实文件夹映射，将散乱的桌面内容纳入分区管理，支持拖入拖出与规则排序，让桌面清新整洁，强烈推荐。

https://github.com/Tianyu199509/DeskBox

![DeskBox使用展示](/images/tools-recommend/1.png)

## ZTools

一个高性能、可扩展的应用启动器和插件平台，uTools 的开源实现，支持 macOS 和 Windows。

https://github.com/ZToolsCenter/ZTools

![ztools使用展示](/images/tools-recommend/2.png)

丰富的插件生态，支持多种功能扩展，满足不同用户的需求。

![ztools丰富插件](/images/tools-recommend/3.png)

## Geek Uninstaller

Geek Uninstaller 是一个 Windows 上的轻量、便携、免费卸载工具，支持强制卸载、清理残留文件和注册表项，适合需要彻底卸载软件的用户。

https://geekuninstaller.com/

![geek uninstaller 官网](/images/tools-recommend/4.png)

## FlClash

一款基于 ClashMeta 的多平台代理客户端，简单易用，开源且无广告。

https://github.com/chen08209/FlClash

![flclash使用展示](/images/tools-recommend/5.png)

## LocalSend

LocalSend 是一个自由、开源的应用程序，允许你在本地网络上安全地与附近设备分享文件和消息，无需互联网连接。局域网快捷文件传输。

https://github.com/localsend/localsend

![LocalSend使用展示](/images/tools-recommend/6.png)

## Everything

干净简洁的用户界面、快速文件索引、快速搜索、最小资源使用、实时更新。一款好用的极速文件搜索工具。

https://www.voidtools.com/zh-cn/

![Everything 使用展示](/images/tools-recommend/7.png)

## Snipaste

Snipaste 是一款免费、无广告的截图与贴图工具，解决 Windows 用户“截图后无法固定在屏幕对照”的痛点。截图后一键将图片贴回桌面置顶显示，支持缩放、取色、标注，写文档、核对数据、对照代码时不用反复切换窗口。

https://zh.snipaste.com/

![Snipaste 使用展示](/images/tools-recommend/8.png)

## ScreenToGif

ScreenToGif 是一款专为 Windows 平台打造的免费、开源的轻量级屏幕录制与 GIF 动画制作工具。写文档、写博客、提 Issue 时要演示操作步骤，录屏后可直接导出 GIF / 视频，还能逐帧编辑、加标注、压缩体积。

https://github.com/NickeManarin/ScreenToGif

![ScreenToGif 使用展示](/images/tools-recommend/1.gif)

## PicList

PicList 是一款高效的云存储和图床平台管理工具，基于 PicGo 深度二次开发。它保留了 PicGo 的所有功能，同时新增了全面的云存储管理能力和多种实用功能以及全新的轻量化脚本系统。

无论你是需要整理云端文件、同步 Markdown 图片，还是轻松管理多个存储平台，PicList 都能通过其美观的界面和强大的插件/脚本系统，简化你的工作流程。

https://github.com/kuingsmile/PicList

![PicList 使用展示](/images/tools-recommend/1.webp)
