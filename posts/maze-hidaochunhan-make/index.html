发布于: 2026-11-22 14:35 · 更新于: 2026-11-23 19:58

设计思路：部署dns服务，选手通过 dns ip反查域名，配置 hosts，域名访问目标系统，目录扫描泄露源码，代码审计发现漏洞，sql盲注拿到目标用户密码哈希，反查获取明文密码登录ssh，sudo 可执行 python 脚本中使用了用户可写的目录，利用 pth 文件导包实现命令执行

修改主机名

hostname="Hidaochunhan"

cat >/etc/hosts <<EOF
127.0.0.1   localhost
127.0.1.1   $hostname
::1         localhost ip6-localhost ip6-loopback
EOF

创建用户及修改密码

useradd -m -s /bin/bash daochunhan
# daochunhan2026
echo 'daochunhan:daochunhan2026' | chpasswd
# 3tV5xUPd06NH8MMsrf1KHyyK

安装配置 dnsmasq

apk add dnsmasq iproute2 bind-tools

创建配置文件

mkdir -p /etc/dnsmasq.d
cat > /etc/dnsmasq.conf <<'EOF'
conf-dir=/etc/dnsmasq.d/,*.conf
bind-dynamic
no-resolv
no-hosts
domain-needed
bogus-priv
local=/dsz/
EOF

开机脚本

cat > /etc/local.d/50-dns.start <<'EOF'
#!/bin/sh
CONF=/etc/dnsmasq.d/10-host.conf

IP=$(ip -4 -o addr show scope global | awk '$2 !~ /^(docker|virbr|br-|veth)/ {split($4,a,"/"); print a[1]; exit}')
[ -n "$IP" ] || exit 0

if [ -f "$CONF" ] && grep -q ",$IP\$" "$CONF"; then
    exit 0
fi

printf 'host-record=daochunhan.dsz,%s\n' "$IP" > "$CONF"
rc-service dnsmasq restart
EOF

chmod +x /etc/local.d/50-dns.start

设为开机启动

rc-update add local default
rc-update add dnsmasq default

立刻生效

rc-service dnsmasq start
/etc/local.d/50-dns.start

验证

cat /etc/dnsmasq.d/10-host.conf

) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

           "鸡公煲", "煎饼果子", "猫条", "小鱼干", "什么都不吃"]

def main():
    with open(CONF) as f:
        conf = json.load(f)

    if conf.get("plugins"):
        site.addsitedir(conf["plugins"])

    w = random.choice(conf.get("weather") or WEATHER)
    m = random.choice(conf.get("food") or FOOD)

    print("我猜明天" + w)

if __name__ == "__main__":
    main()
