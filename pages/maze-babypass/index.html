MazeSec BabyPass

发布于: 2025-11-11 00:01

靶机说明

关键词：密码复用、MD5 彩虹表破解、MySQL 凭证泄露、SSH 横向移动、Web 目录遍历

摘要：本文记录了 MazeSec BabyPass 靶机的渗透过程。选手通过目录扫描发现 tms 系统中的 Readme.txt 文件，获取到 admin 与 anuj 用户的明文密码 Test@123；利用密码复用特性，直接通过 SSH 成功登录 anuj 与 admin 两个低权限用户；在 anuj 用户环境下读取 Web 目录下的配置文件 config.php，获取 MySQL 数据库凭证并登录本地数据库，从 tblusers 表中发现 root 用户的 MD5 哈希值；通过在线彩虹表查询成功破解出明文密码 Root@456，最终使用该密码通过 SSH 登录 root 用户完成权限提升。该靶机重点考察了开发人员的不良操作习惯（明文凭证泄露、密码复用）、数据库哈希值的破解利用以及从 Web 应用到系统权限的横向移动思路。
