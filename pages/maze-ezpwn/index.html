MazeSec ezpwn

发布于: 2025-11-03 12:15

靶机说明

关键词：栈溢出（ret2text）、栈对齐修复、sudo file GTFOBins 滥用、SSH 私钥提取

摘要：本文记录了 MazeSec ezpwn 靶机的渗透过程。选手通过端口扫描发现 9999 端口运行存在 gets 缓冲区溢出的 ELF 程序，利用输入字符位置校验逻辑直接触发后门函数，暴露出内部 11450 端口提供的 ret2text 题目附件；在 ret2text 程序中，通过计算偏移构造 payload 覆盖返回地址，并插入 ret 指令修复栈对齐问题，成功获取 a 用户权限；随后利用 a 用户拥有的 NOPASSWD sudo 权限执行 /usr/bin/file，参照 GTFOBins 利用方式读取 /root/.ssh/id_rsa 私钥，经格式处理后实现免密登录 root，完成权限提升。该靶机重点考察了基础栈溢出利用、栈对齐原理以及 sudo 二进制程序配置缺陷的实战利用。
