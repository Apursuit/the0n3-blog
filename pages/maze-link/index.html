MazeSec link

发布于: 2025-10-30 17:03

靶机说明

关键词：WordPress XML-RPC 密码爆破、软链接文件读取、docker 组特权滥用、Docker 容器逃逸

摘要：本文记录了 MazeSec link 靶机的渗透过程。选手通过端口扫描发现 80 端口运行 WordPress 6.7，利用 wpscan 枚举出用户 yliken，借助 XML-RPC 接口爆破获取登录凭证，进入后台修改主题文件植入 WebShell，获取 www-data 权限；随后发现宿主机内部 8080 端口运行 yliken 用户的文件浏览服务，利用 www-data 对该服务目录的写权限创建软链接，将 yliken 的 user.txt 与 SSH 私钥映射至 Web 目录，读取私钥后登录 yliken 用户；最终发现 yliken 属于 docker 组，通过挂载宿主机根目录至容器并切换容器根目录的方式完成 Docker 逃逸，获取宿主机 root 权限。该靶机重点考察了 WordPress 历史接口利用、Linux 软链接特性以及容器环境特权滥用等实战技巧。

ln -s /home/yliken/.ssh/id_rsa /app/yliken/key.txt

docker逃逸

ssh登录yliken后，没有发现suid命令，发现yliken在docker组里，可以使用docker命令

docker 有ubuntu镜像，可以利用docker提权
