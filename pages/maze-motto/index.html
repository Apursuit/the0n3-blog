MazeSec motto

发布于: 2025-11-12 16:35

靶机说明

关键词：二阶 SQL 注入、sqlmap 自动化利用、密码复用、bash 比较注入、SUID bash 提权

摘要：本文记录了 MazeSec motto 靶机的渗透过程。选手通过端口扫描发现 9090 端口运行着定制 Web 服务，在修改用户昵称处插入恶意载荷后发现座右铭展示页面出现了数据泄露，确认为二阶 SQL 注入漏洞；利用 sqlmap 的 --second-url 参数自动化攻击，从数据库中导出用户凭证，使用 RedBean/cannotforgetyou 成功登录 SSH；在 redbean 用户目录下发现 .backup 备份文件夹，审计其中的 C 源码与 Shell 脚本发现 run_newsh 设置了 SUID 位且内部调用了存在缺陷的 new.sh；利用 bash 脚本中未加引号的变量比较漏洞（$1 = "flag" 与 [ $1 = "flag" ] 的解析差异），传入含空格的参数绕过安全限制，触发 chmod +s /bin/bash 逻辑；最终执行带权限的 bash -p 获取 root 权限。该靶机重点考察了二阶注入的联动利用、源码审计以及 Shell 脚本因引号缺失导致的权限提升风险。

6. bash 比较注入

家目录存在备份目录 .backup，内含 new.sh 与 run_newsh.c：

bash-5.0$ ls -lah
total 16K
drwxr-xr-x 2 root    root    4.0K Jul 31 08:27 .
drwxr-xr-x 3 redbean redbean 4.0K Nov 12 05:59 ..
-r--r--r-- 1 root    root    1.7K Jul 31 02:46 new.sh     
-rw-r--r-- 1 root    root     509 Jul 31 08:27 run_newsh.c

run_newsh.c 核心逻辑（以 root 权限调用 /opt/new.sh 并传参）：

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>

int main(int argc, char *argv[]) {
    if (argc != 2) {
        fprintf(stderr, "Usage: %s <arg>\n", argv[0]);
        return 1;
    }
    setuid(0);
    setgid(0);
    char *script = "/opt/new.sh";
    char *args[] = { script, argv[1], NULL };
    execv(script, args);
    perror("execv failed");
    return 1;
}

new.sh 关键判断（节选）：

14  [ -n "$1" ] || exit 1
15  [ "$1" = "flag" ] && exit 2
16  [ $1 = "flag" ] && chmod +s /bin/bash

说明：

  • 15 行使用了被引号包裹的参数比较。
  • 16 行未加引号，存在单词分割/空白影响的风险。

系统 SUID 文件检索：

redbean@motto:~$ find / -perm -4000 -type f 2>/dev/null
/opt/run_newsh

7. 提权利用与验证

利用未加引号的比较差异，传入包含空格的参数，使 15 行判断不等而 16 行判断等，从而为 /bin/bash 赋予 SUID：
