tldr安装配置中文

发布于: 2025-09-23 17:24

什么是tldr？

一个命令帮助手册，快速查看命令的使用方法，这个工具会直接给出多个使用示例，可以覆盖大部分场景，对于新手来说非常友好。

安装

在windows,linux,macos操作系统都可以安装使用，如果要使用中文版本，推荐使用pipx安装，npm安装不能修改为中文版本

推荐pipx安装

pipx install tldr

npm安装

npm install -g tldr

macOS使用brew安装

brew install tldr

配置中文

设置环境变量

windows

setx TLDR_LANGUAGE "zh"
setx TLDR_CACHE_ENABLED "1"

linux操作系统

先检查当前shell

echo $SHELL

pipx 安装后，可执行文件通常位于 ~/.local/bin，如果用户的 Shell 配置文件里还没有这个路径，需要手动加入 PATH。

如果是bash，配置环境变量到~/.bashrc文件中

echo 'export TLDR_LANGUAGE="zh"' >> ~/.bashrc
echo 'export TLDR_CACHE_ENABLED=1' >> ~/.bashrc
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc

如果是zsh，配置环境变量到~/.zshrc文件中

echo 'export TLDR_LANGUAGE="zh"' >> ~/.zshrc
echo 'export TLDR_CACHE_ENABLED=1' >> ~/.zshrc
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc

bash下，使环境变量立即生效

source ~/.bashrc

zsh下，使环境变量立即生效

source ~/.zshrc

完成后，重新开一个终端，更新tldr缓存

tldr -u
